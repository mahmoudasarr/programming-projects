# C++ Digital Clock

A simple digital clock made with C++.

## Features

- Takes the hour, minute, and second from the user.
- Updates the time every second.
- Handles seconds, minutes, and hours.
- Runs in the Linux terminal.

## Technologies

- C++
- Linux
- Git

## How to Run

Compile:

```bash
g++ main.cpp -o clock
```

Run:

```bash
./clock
```
